rppg pipeline

camera-based signal estimation experiment

devpost github

This project explored whether subtle color changes in ordinary camera video could be processed into a pulse-related signal without a contact sensor. I developed and tested an rPPG pipeline as a computer-vision experiment, using a Jetson Orin Nano as the embedded test platform. The project produced a runnable prototype and public codebase for continued experimentation; it is not presented as a clinically validated measurement system.
